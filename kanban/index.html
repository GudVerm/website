GitHub für Drag & Drop verbinden

Damit diese statische GitHub-Pages-Seite den Status eines Issues ändern kann, braucht sie eine Schreibberechtigung für genau dieses Repository.

  1. Erstelle bei GitHub einen Fine-grained personal access token.
  2. Repository access: nur SebMut/Smartwerk-Presentation.
  3. Repository permissions → Issues: Read and write. Weitere Schreibrechte sind nicht nötig.
  4. Token unten einfügen. Er wird nur in sessionStorage dieses Browser-Tabs gespeichert.
Den Token niemals in GitHub-Dateien eintragen und auch nicht im Chat teilen.
