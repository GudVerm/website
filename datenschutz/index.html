Technische Bereitstellung

Die öffentliche Website wird über GitHub Pages ausgeliefert. CMS-Inhalte, Medien, Kontaktanfragen und die eigene Website-Statistik werden über einen Cloudflare Worker sowie Cloudflare D1 und R2 verarbeitet. Bei der technischen Auslieferung von Internetseiten erhalten die beteiligten Infrastruktur-Dienste zwangsläufig Verbindungsdaten einer Anfrage. Die eigens entwickelte Analytics-Datenbank speichert jedoch keine IP-Adresse und kein persönliches Besucherprofil.

Kontaktformular

Wenn das Kontaktformular verwendet wird, werden Name, E-Mail-Adresse, Betreff, Nachricht, der Seitenpfad der Anfrage und ein Zeitstempel an den Cloudflare Worker übermittelt und in der dafür vorgesehenen D1-Tabelle für Projektanfragen gespeichert. Im Admin können zusätzlich Status und eine interne Notiz gepflegt werden. Diese Inhalte werden nicht in die Website-Statistik kopiert.

Für neue Projektanfragen wird außerdem eine E-Mail-Benachrichtigung an gudeliusvermessung@web.de ausgelöst. Das Kontaktformular funktioniert unabhängig von der Statistikfunktion.

Datensparsame Website-Statistik

Für die Statistik werden ausschließlich der Ereignistyp, ein normalisierter Seitenpfad, ein kurzes Ziel bzw. Label und der Zeitpunkt gespeichert. Erfasst werden beispielsweise Seitenaufrufe, relevante Navigations- und CTA-Klicks, Öffnungen von Leistungs- oder Technikbereichen sowie Kontaktaktionen.

In der Analytics-Tabelle werden ausdrücklich keine Namen, E-Mail-Adressen, Telefonnummern, Formularnachrichten, vollständigen IP-Adressen, Fingerprints, vollständigen User-Agent-Zeichenketten oder dauerhaften Besucherkennungen gespeichert. Für diese Statistik werden keine Cookies oder persistenten Besucher-IDs gesetzt.

Analytics-Rohereignisse werden maximal 370 Tage vorgehalten. Danach werden sie aus der Analytics-Tabelle entfernt. Die Statistik dient nur einer aggregierten Auswertung der Website-Nutzung.

Externe Bildquellen

Im aktuellen Beta-Stand werden einzelne Fallback- und Platzhalterbilder noch von externen Bild-/Hersteller-Servern geladen. Beim Abruf solcher Bilder stellt der Browser eine direkte Verbindung zum jeweiligen externen Server her. Diese externen Bildabrufe sind technisch von der eigenen Analytics-Funktion getrennt.

Keine versteckten Besucherprofile

Die Website versucht nicht festzustellen, welche konkrete Person mehrere Seiten nacheinander besucht. Deshalb zeigt der Admin Seitenaufrufe und Interaktionen, aber keine künstlich berechnete „Unique-Visitor“-Zahl.
